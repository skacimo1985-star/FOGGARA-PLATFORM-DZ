# FOGGARA-DZ

منصة WEFEH قيد التطوير بواسطة EURL SIREP Oasis Nexus WEFEH، بواجهة عربية RTL وفرنسية وإنجليزية LTR. تبدأ قاعدة البيانات دون حسابات أو مشاريع أو قياسات جاهزة. يُنشئ المستخدم مؤسسته عبر `/register`؛ التسجيل لا يمثل تحققًا قانونيًا من هويتها.

## التشغيل

Python 3.12+ وNode.js 20+. على Windows: `run-local.bat` أو `run-local.ps1`.

```sh
cd backend
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.lock
python -m alembic upgrade head
python -m uvicorn app.main:app --port 8000
```

وفي نافذة أخرى من `app`: `npm ci` ثم `npm run dev`. الواجهة: `http://localhost:3000`، API: `http://localhost:8000/api/health`. SQLite مخصص للتطوير. لا يتم إنشاء بيانات أعمال عند الإقلاع؛ `backend/seed.py` أصبح أداة اختيارية لتهيئة كتالوج المؤشر الحسابي فقط.

## محرك القرار Rust

النواة في `engines/nexus-core` تنفذ المقارنة بين بدائل المستخدم بقيود صلبة وتطبيع min–max للأوزان. لا تتصل بأجهزة أو شبكات أو قاعدة البيانات. تفاصيل الدقة والحدود موثقة في README الخاص بها.

```sh
cd engines/nexus-core
cargo build --release --locked
cargo test --locked
cargo clippy --locked --all-targets -- -D warnings
```

فعّلها في الباكند عبر `NEXUS_MATRIX_ENGINE=rust` و`NEXUS_RUST_BINARY` كمسار مطلق للملف التنفيذي. حد الإدخال 1 MiB ومهلة التشغيل 5 ثوانٍ؛ فشل المحرك يعيد 503 دون استبداله خفيةً بمحرك آخر. تحفظ المدخلات وبصمتها وإصدار الخوارزمية؛ النتيجة مقترحة وليست أمر تشغيل. التنفيذ البديل Python/Decimal يحمل إصدارًا مختلفًا. صور Docker تتضمن محرك Rust وتختاره افتراضيًا.

## الوظائف المتاحة

- التسجيل ودعوات المؤسسة والأدوار وعزل بيانات المؤسسات وسجل التدقيق.
- المشاريع والموارد في المجالات الخمسة، القياسات ومراجعتها والأدلة ومرفقاتها والقرارات البشرية والإجراءات.
- مقارنة سيناريوهات WEFEH وحفظها واقتراح قرار موثق منها. لا تمثل الأوزان والحدود التي يصرح بها المستخدم قواعد تنظيمية معتمدة.
- غرف بيانات بصلاحيات وصول ومشاركة أدلة محددة وأسئلة وأجوبة وإلغاء الوصول وتتبعه. تحقق الهوية الرسمي غير موصول.
- احتياجات وعروض بموافقة نشر ومطابقة قواعد معلنة، مخاطر وجاهزية وسلسلة ضمان تجاري بمبالغ DZD.
- بيانات زراعية مرتبطة بالمصدر: تحاليل تربة، رطوبة، مؤشرات نباتية ومائية من نطاقات مستوردة، طقس مستورد ومراجع، تقدير ري وتقويم محصول وملاحظات وتشخيص خبير. لا توجد تغذية أقمار صناعية أو طقس حية أو نموذج تشخيص صور تلقائي مهيأ.
- عرض مكاني أساسي وسجلات IoT وقياسات ومحاكاة منفصلة. التكامل الكامل مع PostGIS/MapLibre وMQTT والأجهزة الميدانية ما زال يتطلب التنفيذ والتحقق.
- قصرية رمزية متحركة بـCanvas، إيقاف وسرعة وتقليل حركة؛ ليست خريطة حقل ولا قياسات فعلية. واجهة متجاوبة وPWA تحفظ الغلاف العام فقط؛ البيانات الخاصة تحتاج اتصالًا وتسجيل دخول. تطبيق أصلي منشور للهواتف غير متوفر.

## الأمان والإنتاج

`Dockerfile.prod` يستخدم PostgreSQL خارجيًا وحساب حاوية غير root وفحص صحة. انسخ `.env.example` واضبط أسرارًا قوية. `ENV=prod` يرفض SQLite وسر JWT الافتراضي أو الضعيف وأصول CORS غير HTTPS/الصريحة. لا تستخدم صورة PostgreSQL المضمنة للإنتاج. تهيئة TLS والنسخ الاحتياطي والتشفير والمراقبة والاستعادة والإقامة الجزائرية للبيانات مسؤولية نشر يجب اختبارها؛ وجود Docker لا يثبت تنفيذها.

كلمات المرور PBKDF2-SHA256 مع 600,000 دورة وترقية التجزئات القديمة عند الدخول. التوكن يفرض المصدر والجمهور والصلاحية وبصمة الاعتماد، وتغيير كلمة المرور يبطل الجلسات السابقة. الواجهة تحتفظ بالتوكن في الذاكرة فقط. المرفقات محدودة النوع والحجم والوصول. ما زال يلزم MFA وتعليق الحسابات وإبطال جلسة فردية وحماية إضافية ضد الإساءة موزعة واختبار اختراق مستقل. لا يوجد ادعاء بإزالة جميع الثغرات أو شهادة أمان.

[سجل المصادر القانونية والهندسية](docs/LEGAL_SOURCE_REGISTER.md) يوثق النصوص الرسمية الحالية والمسؤوليات. تحقق الإدارة والمستشار القانوني والسلطات المختصة من الإجراءات والتصاريح وسياسات الاحتفاظ وحقوق الأشخاص قبل التشغيل التجاري. المنصة لم تحصل على شهادة امتثال.

## التحقق

```sh
# من backend؛ استخدم قاعدة اختبار منفصلة لأنها تُمسح للاختبارات.
TEST_DATABASE_URL=sqlite:////tmp/foggara-tests.db python -m pytest tests/ -q
# لتفعيل اختبارات التكامل الفعلية مع Rust:
NEXUS_RUST_TEST_BINARY=/absolute/path/foggara-nexus-core TEST_DATABASE_URL=sqlite:////tmp/foggara-tests.db python -m pytest tests/ -q
# من app:
npm run lint
npm run build
npm audit
```

CI يطبق المهاجرات ويختبر PostgreSQL وRust والواجهة. [خارطة البنية وحدود الإنجاز](NEXUS_BLUEPRINT.md) و[تراخيص المكونات](THIRD_PARTY_NOTICES.md) مكملان لهذه الوثيقة. لا تعتبر نجاح الاختبارات اعتمادًا هندسيًا أو قانونيًا أو ضمانًا خلوًا من الثغرات.
